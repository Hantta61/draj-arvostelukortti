# DRAJ arvostelukortti (PWA)

Dreeverien ajokokeen arvostelukortti: perustiedot, ajanotto maastossa, GPS-reitit kartalla ja pisteytys
Kennelliiton "Dreeverien ajokokeen (DRAJ) säännöt" (voimassa 1.8.2018) mukaan.

**Sovellus:** https://hantta61.github.io/draj-arvostelukortti/

## Asennus puhelimeen
1. Avaa osoite puhelimen selaimessa.
2. Android (Chrome): valikko ⋮ → *Asenna sovellus*. iPhone (Safari): jakopainike → *Lisää Koti-valikkoon*.
3. Sovellus toimii sen jälkeen myös ilman verkkoyhteyttä; tiedot tallentuvat laitteeseen.

## Pisteytys
- **Ajoaika** enintään 65 p = 65 × ajoaika / 180. Ajoerät 120 ja 60 min (ohjaaja valitsee järjestyksen), hakuaikaa yhteensä 240 min. Hyväksytty ajoaika = erän pituus − vähintään 5 min hukat − ajolöysyys.
- **Ominaisuudet** 7 × 0–5 p puolen pisteen tarkkuudella, tuomarien ja erien keskiarvona. 0 p jostakin kohdasta → sulkeminen.
- **Palkinnot:** dreeverit 75 / 60 / 45 p, bassetit 60 / 50 / 40 p, alppienajokoira 40 / 30 / 20 p.

## Reitit
Ryhmän GPS-reitti puhelimesta, sijainti jokaiseen tapahtumaan ja koiran reitti paikantimesta (GPX/KML). Kartta: OpenTopoMap / OpenStreetMap.
